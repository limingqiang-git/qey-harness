# 安全规范(防御性编码,AI 最易漏)

> 安全问题往往"不报错但留坑":注入、泄露、越权。本文件约束通用安全底线,语言无关。

## 输入与注入

- **永远不拼 SQL/命令**——用参数化查询/预编译/ORM,禁止字符串拼接进 SQL。
- **HTML 输出转义**防 XSS;用户内容进 HTML 必转义,进 JS 必 JSON encode。
- **校验所有外部入参**——类型/长度/范围/格式;白名单优先于黑名单。
- **路径校验**——用户传入的文件路径规范化后校验在允许目录内(防 `../` 穿越)。

## 密钥与敏感信息

- **密钥/密码/token 用环境变量或密钥管理**,绝不硬编码进源码。
- **敏感信息不进日志**——密码、token、身份证、卡号、完整手机号打日志前脱敏(如 `138****1234`)。
- **敏感信息不进 git**——`.env`/密钥文件进 `.gitignore`;commit 前查 diff 有无泄露。
- **错误响应不泄露内部**——对外只给错误码 + 通用信息,不返回堆栈/SQL/内部路径。

## 权限与越权

- **涉及资源的操作校验权限**——不只是"登录了",还要"对这条数据有权限"(防越权/IDOR)。
- **写操作做 CSRF 防护**(token / SameSite)。
- **鉴权失败与权限失败区分**——未登录(401) vs 无权限(403),别混。

## 真实正反对照(来自 westmonth 代码扫描)

> 真实代码提炼,带 file:line。以下多为**真漏洞级别**,重点对照。

### 1. 字符串插值拼原生 SQL

❌ 反例:
```php
$casePrice .= "WHEN id = {$data['id']} THEN {$data['price']} ";   // 入参插值可注入
DB::update("UPDATE order_products SET price = CASE $casePrice END WHERE id IN ($idsList)");
->whereRaw("{$params['amount']} <= payer_trade_amount");   // "laravel会绑错"放弃绑定
```
✅ 正例:
```php
$casePrice = implode(' ', array_map(fn($i) => "WHEN id = ? THEN ?", $rows));
$bindings = [];
foreach ($rows as $row) { $bindings[] = (int)$row['id']; $bindings[] = (float)$row['price']; }
DB::update("UPDATE order_products SET price = CASE {$casePrice} END WHERE id IN (?)", array_merge($bindings, [$idList]));
->whereRaw('? <= payer_trade_amount', [(float)$params['amount']]);
->whereIn('customer_id', $customerIds);
```
**为什么**: 入参 `{$var}` 插 SQL 可注入;"laravel 会绑错"是错误理由(占位符与 bindings 数量不匹配应排查)。一律 `?` 占位 + bindings,数值强转,IN 用 whereIn。
**来源**: beike/ShopAPI/Controllers/ManualController.php:637、Quotax/QuotaxPeriodService.php:3389

### 2. 硬编码凭据 + env fallback 写真实密钥

❌ 反例:
```php
$appSecret = '2a17114434fb24c9a5827d5458c51b49';   // 字面量进版本库
'password' => env('DB_PASSWORD', 'xxBIuulmqraji1qQV5oa'),  // fallback 写真实口令
$nonceStr = 'fb22fff75c27';   // nonce 写死,防重放失效
```
✅ 正例:
```php
'app_secret' => env('THIRD_PARTY_APP_SECRET'),   // 不配则报错
$nonceStr = bin2hex(random_bytes(8));   // 每次随机
public function __construct(private ?string $token = env('XXX_API_TOKEN')) {
    if ($this->token === null) throw new \RuntimeException('凭据未配置');
}
```
**为什么**: 凭据字面量进库无法按环境轮换;nonce 应随机防重放;`env(KEY,'真实口令')` 把生产凭据当默认值,缺失静默用默认密钥。fallback 应空,缺失报错。
**来源**: config/database.php:186、beike/Services/KsoldService.php:17、ShopAPI/Controllers/BaseService/UserInfoController.php:225

### 3. eval 执行外部公式 + 弱黑名单

❌ 反例:
```php
$pattern = "/[^0-9+\-*\/().]/";
throw_if_error(preg_match($pattern, $formula), '违禁词');
$freight = (float)eval("return round($formula, 2);");   // eval 数据库来的公式
```
✅ 正例:
```php
// 安全表达式求值器:解析成 AST,仅允许白名单运算符 + 变量
$ast = ExpressionParser::parse($formula);
$result = $ast->evaluate(['weight' => $weight, 'volume' => $volume]);
```
**为什么**: eval 执行数据库/后台公式,正则黑名单极易漏(漏一字符即被绕过),公式可被篡改注入任意 PHP。用安全求值器(白名单 AST),绝不外部字符串进 eval。
**来源**: beike/Repositories/FreightQuotationRepo.php:491

### 4. 文件路径穿越(入参直接拼路径)

❌ 反例:
```php
$imagePath = $request->get('path');
$folder = public_path("catalog{$imagePath}");   // 无 '../' 过滤
$this->fileManagerService->zipFolder($folder);  // 打包任意目录供下载
```
✅ 正例:
```php
$base = realpath(public_path('catalog'));
$real = realpath($base . '/' . ltrim($request->get('path'), '/'));
if ($real === false || ! str_starts_with($real, $base . DIRECTORY_SEPARATOR)) {
    abort(403, '非法路径');
}
return $this->fileManagerService->zipFolder($real);
```
**为什么**: 入参拼路径无 realpath 归一化 / 无 `..` 拒绝 / 无基目录白名单,客户端传 `../../../etc` 即可穿越打包任意目录,泄露配置/密钥/源码。
**来源**: beike/Admin/Http/Controllers/FileManagerController.php:190
